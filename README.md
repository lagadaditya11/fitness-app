# FitTrack — Calorie & Workout Tracker

Full-stack web app: Java/Spring Boot backend + PostgreSQL + React frontend.

Read the full explanation here: **[docs/README.md](docs/README.md)**

Quick start:

```bash
docker compose up -d postgres
cd backend && mvn spring-boot:run      # backend on :8080
cd frontend && npm install && npm run dev   # app on http://localhost:5173
```
